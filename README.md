# Vyral District

![Vyral District logo](assets/logo.png)

**Brand:** black (`#000`) and smoke grey (`#9b9b9b`), set in Helvetica-style bold type to match the logo. The logo files are `assets/logo-full.jpg` (original), `assets/logo.png` (circle crop), `assets/favicon.png` and `assets/apple-touch-icon.png`.

**Where accounts go to blow up.** Vyral District promotes social media growth and paid growth.

This repo has:

| Part | File | What it does |
|---|---|---|
| Social page | `index.html` | The brand's home page: profile header, services, an ad feed with captions and hashtags, packages, and an audit sign-up. |
| Ad Studio | `studio.html` | Generates new ads in the brand voice for any niche. You can edit them, preview the caption and hashtags for each platform, play the voiceover, download a PNG and queue ads for posting. |
| Ads | `data/ads.json` | 8 ready-to-run ads, each with a headline, body, CTA, voiceover script and 12 hashtags. |
| Ad images | `assets/ads/*.png` | 1080×1080 images for every ad, rendered with `npm run render`. |
| Auto-poster | `autopost/post.mjs` | Posts the next unposted ad to X, a Facebook Page and Instagram, trimming the hashtags to suit each platform. |
| Video ads | `videos/out/*.mp4` | 5 animated paid-growth video ads with voiceover and music, each in 9:16, 1:1 and 16:9 (15 MP4s). |
| Schedule | `.github/workflows/autopost.yml` | Runs the auto-poster 3 times a day on GitHub Actions. |

To upload them as paid ads, use TikTok Ads Manager, Meta Ads Manager (Instagram and Facebook), Google Ads (YouTube) and X Ads. When you post them organically, use the hashtags from `data/videos.json`.

### 3D engine

The videos are rendered in real 3D with Three.js (`videos/engine3d.html`):

- extruded smoke-grey type that flies in from depth
- a metal ring echoing the logo circle, orbiting behind the content
- 3D bars, slabs, badges and a CTA pill
- drifting smoke and dust
- a slowly orbiting camera
- an end card that rebuilds the logo lockup in 3D

The older flat engine is still available with `--2d`. Rendering runs on the CPU at about 0.3s per frame, so a full batch of 25 videos takes about an hour.

### Make or edit videos

Scripts and scenes live in `data/videos.json`. The scene types are `hook`, `line`, `counter`, `list`, `chart`, `split` and `cta`. Wrap words in `*asterisks*` to highlight them.

```bash
pip install kokoro-onnx soundfile numpy
# download the voice model (kokoro-v1.0.int8.onnx and voices-v1.0.bin) from
# https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0
python3 videos/audio.py --model kokoro-v1.0.int8.onnx --voices voices-v1.0.bin   # voiceover + music
node videos/render.mjs                    # renders all videos (needs ffmpeg + Playwright)
node videos/render.mjs --only pv-02 --format 9x16
node videos/render.mjs --preview          # stills of each scene, for a quick check
```

The voice is Kokoro `am_michael` at 1.08× speed: confident and energetic. To change it, edit `voice` in `data/videos.json`; for example, `am_onyx` is deeper and `af_bella` is a female voice. The music is a royalty-free beat generated by `videos/audio.py`, so there are no licensing issues.

## Affiliate link (Instant Boost)

The affiliate link `https://smmfollows.com/ref/tqtwi` appears in three places:

- **`links.html`**: the link-in-bio page, with the affiliate link at the top. Put `https://<your-site>/links.html` in the TikTok, Instagram and X bios. Every post caption says "link in bio".
- **`index.html#boost`**: the Instant Boost section, plus a button in the hero.
- **`data/ads.json` → `brand.affiliate`**: one place to change the link.

Every placement says it's an affiliate link (the FTC requires that), and the links use `rel="sponsored"`.

**The link is intentionally kept out of auto-posted captions, videos and paid ads.** TikTok, Instagram, Facebook, YouTube and X all ban promoting bought followers or engagement in posts. Ads that do it get rejected, and accounts that do it repeatedly can be restricted or banned. Posts send people to the bio page, and the bio page sends them on to the offer.

## TikTok auto-posting

`.github/workflows/tiktok.yml` posts to your TikTok **3 times a day** at peak US engagement times (Eastern):

| Slot | Time (ET) | Why |
|---|---|---|
| Morning | ~7:45am | Commute and before-work scrolling |
| Lunch | ~12:15pm | Lunch-break spike |
| Prime time | ~7:40pm | Highest daily usage |

The cron times are in UTC and set for Eastern **Standard** Time. When daylight saving starts in March, subtract 1 from each UTC hour. Once you have a few weeks of posts, check TikTok Studio → Analytics → Followers → "Most active times" and move the slots to match your actual audience.

**Posting order:** two tips (`og-*`), then one paid-growth pitch (`pv-*`), repeating. Each video is posted once, since TikTok holds back reach on re-uploads. At 3 posts a day the 15 videos last 5 days, so add a new batch each week (`data/videos.json` → `videos/audio.py` → `videos/render.mjs`). The poster stops and says so when it runs out.

**Captions:** the hook, then the CTA with "link in bio", then 4–6 hashtags (brand + niche + `#fyp`). Each post is marked as promoting your own business (`brand_organic_toggle`), which TikTok requires for brand content.

### Connect your TikTok account (one time, ~15 min)

1. Go to **developers.tiktok.com** → Manage apps → **Create app**. Add the **Login Kit** and **Content Posting API** products, and turn on **Direct Post**. Scopes: `user.info.basic`, `video.upload` and `video.publish`.
2. Add the redirect URI `https://<your-site>/tiktok-callback.html`. This page is included in the repo, so it works once the site is deployed.
3. Run the login helper and approve the app as your Vyral District account:
   ```bash
   TIKTOK_CLIENT_KEY=... TIKTOK_REDIRECT_URI=https://<your-site>/tiktok-callback.html node autopost/tiktok-auth.mjs
   # open the link, approve, copy the code from the callback page, then:
   TIKTOK_CLIENT_KEY=... TIKTOK_CLIENT_SECRET=... TIKTOK_REDIRECT_URI=... node autopost/tiktok-auth.mjs <code>
   ```
4. In GitHub → Settings → Secrets and variables → Actions:
   - **Secrets:** `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET`, `TIKTOK_REFRESH_TOKEN`
   - **Variables:** `POST_LIVE=true`
5. Test it: Actions → **Vyral District TikTok posts** → Run workflow.

> ⚠️ **Public posts need TikTok's app audit.** Until TikTok approves your app (submitted from the developer portal, usually a few days to a couple of weeks), the API can only post **private (Only me)** videos. The poster detects this, posts privately and warns you. After approval, posts go public automatically. The refresh token lasts a year.

## Turn on auto-posting

The auto-poster is a **dry run by default**. To go live:

1. **Host the site** (GitHub Pages, Vercel or Netlify) so the ad images have public URLs. Instagram needs them.
2. In GitHub, go to **Settings → Secrets and variables → Actions** and add:
   - **Secrets** (add only the platforms you use):
     - X: `X_API_KEY`, `X_API_SECRET`, `X_ACCESS_TOKEN`, `X_ACCESS_SECRET` (from developer.x.com; the app needs Read and Write)
     - Facebook Page: `FB_PAGE_ID`, `FB_PAGE_TOKEN` (a long-lived Page access token)
     - Instagram Business or Creator account linked to that Page: `IG_USER_ID`
   - **Variables**:
     - `IMAGE_BASE_URL`, for example `https://yourdomain.com/assets/ads`
     - `POST_LIVE` = `true`
3. Test it: **Actions → Vyral District auto-post → Run workflow**.

Each run posts the next ad in `data/ads.json` and records it in `autopost/state.json`. After every ad has gone out, it starts again from the first. To add more ads, build them in Ad Studio, click **Export for auto-poster**, replace `data/ads.json` with the exported file, then run `npm run render`.

> TikTok doesn't allow organic photo posts through a simple API. Use the TikTok captions and voiceover scripts from Ad Studio for TikTok videos, or run them as paid TikTok ads.
